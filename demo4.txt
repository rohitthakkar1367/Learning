//core idea for the why we need to integrate the Secure Route  in ou fullstack web app 
initialized = false  → still asking the backend (show "Loading...")
initialized = true   → we have an answer
   isAuthenticated = true   → show the page
   isAuthenticated = false  → redirect to /login













User clicks "Log Out"
 ↓
dispatch(logoutUser())
 ↓
POST /api/auth/logout → session destroyed server-side
 ↓
logoutUser.fulfilled reducer runs:
    state.user = null
    state.isAuthenticated = false
 ↓
Home.tsx re-renders (user is now null)
 ↓
BUT — Home.tsx is rendered INSIDE <ProtectedRoute>
 ↓
ProtectedRoute re-renders too (it reads isAuthenticated from the same store)
 ↓
isAuthenticated is now false
 ↓
ProtectedRoute returns <Navigate to="/login" replace />
 ↓
User is redirected
